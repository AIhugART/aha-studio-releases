# AHA Studio

Bộ công cụ AI cho người sáng tạo. Ảnh được tạo **trên máy bạn**, bằng phiên đăng nhập của **chính
bạn** với nhà cung cấp AI — không byte pixel nào đi qua máy chủ của chúng tôi.

## ⬇ Tải về và cài đặt

Toàn bộ hướng dẫn — tải, cài, đăng nhập, tạo ảnh đầu tiên — nằm trên trang chính thức, viết từng
bước cho người chưa từng cài plugin Photoshop bao giờ:

**→ [ahastudio.aihug.art/download](https://ahastudio.aihug.art/download)**

Repo này **chỉ là nơi chứa file**. File `.exe` nằm ở tab **Releases** bên phải, không nằm trong
danh sách file của trang này — git giữ lại mọi phiên bản của mọi file vĩnh viễn, nên gói cài đặt
được phát hành riêng thay vì lưu trong repo. Nếu bạn đang đọc trang này để tìm cách cài đặt, trang
trên đã đầy đủ hơn — bao gồm cả cách qua cảnh báo của Windows, cách cài panel vào Photoshop, và
cách tạo ảnh đầu tiên khi extension trình duyệt chưa phát hành.
